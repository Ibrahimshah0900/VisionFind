A little help

Photos

Attach up to ten images at once. Refer to them as “image 1” or “image 2.” You can combine requests: describe all images, compare two, then draw boxes on a selected image.

Videos

Attach one video, up to 30 seconds and 100 MB. Ask for supported object boxes, counts or detection timestamps. Processing can take time. Boxes update in the processed video; this is not live inference. Movement descriptions are experimental.

Your composer

Enter sends. Shift + Enter adds a line. Attachments stay small; click a thumbnail to see it larger. The microphone uses your browser’s speech recognition when available. Review the text before sending. This local microphone does not yet use the Kaggle Whisper model, and browser recognition may use an external speech service.

Connection

Keep Kaggle running. If its tunnel URL or API token changes, stop the local server, run configure.py again, and restart it. A Kaggle restart clears backend conversations.
